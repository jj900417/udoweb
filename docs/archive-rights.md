# 사진·자료 저작권 운영 원칙

## 기본

- **저작권은 작가 또는 적법한 권리자에게 남는다.** 아카이브에 실린다고 권리가 넘어오지 않는다.
- **웹 게시 허락 ≠ 소유 ≠ 전시 ≠ 출판 ≠ 상품화.** 각각 따로 받는다.
  데이터에서도 `webDisplayAllowed` / `exhibitionAllowed` / `publicationAllowed` 로 나눠 적는다.
- 허락 범위를 **레코드에 적어 둔다.** 기억이나 구두 약속에 남기지 않는다.

## rightsStatus 4단계

| 값 | 뜻 | 공개 |
|---|---|---|
| `verified` | 권리자 확인 + 웹 게시 허락 확인 | 공개됨 |
| `pending` | 확인 중 | 공개 안 됨 |
| `restricted` | 게시 불가(또는 조건부) | 공개 안 됨 |
| `unknown` | 권리자 미상 | 공개 안 됨 |

`verified` 가 아닌 자료는 `publishStatus` 가 `published` 여도 화면에 나오지 않는다
(repository 가 인덱스 단계에서 뺀다).

## 지키는 것

- credit 을 화면에서 빠뜨리지 않는다. 작품 페이지에 `creditLine` 이 항상 붙는다.
- **다운로드 버튼을 만들지 않는다.** 별도 권한 확인 없이 원본을 내보내지 않는다.
- 허락되지 않은 **고해상도 원본을 저장소에 넣지 않는다.** 웹에는 표시용 파생본만.
- 출처(`sourceIds`)를 비워 두지 않는다. 어디서 온 자료인지 적는다.
- 이미 돌아가신 분의 사진·글도 **공개 가능하다고 가정하지 않는다.** 유족·권리 승계를 확인한다.
- 저작권 있는 책의 본문을 대량으로 옮기지 않는다. 우리가 정리·요약하고 원자료를 가리킨다.

## 사진 크기

| variant | 용도 | 비고 |
|---|---|---|
| `thumb` | 목록 | 긴 변 400px 내외 |
| `display` | 상세 | 긴 변 1600px 내외 — 웹 공개용 |
| `full` | 보존용 원본 | **웹에 올리지 않는다** |

`mediaUrl()` 은 `full` 을 임의로 노출하지 않는다.
