# 디자인 레퍼런스 — 무엇을 배우고 무엇을 배우지 않았나

UdoWeb 의 아카이브 화면은 미술관·아카이브 사이트들을 **조사한 뒤** 설계했다.
가져온 것은 **문제 해결 방식(원리)** 뿐이다. 코드·CSS·HTML 구조·이미지·아이콘·폰트·
문안·로고·브랜드·내비 명칭은 **하나도 가져오지 않았다.** 최종 화면은 UdoNow 의 디자인
언어(브랜드 시안, 플랫 카드, 신호색 분리)를 유지한 별개 결과물이다.

## 채택한 원리

| 출처 | 그들이 푼 문제 | UdoWeb 이 가져온 해법 | 적용 위치 |
|---|---|---|---|
| **Foam** (사진 미술관) | 사진마다 비율이 다른데 격자에 맞추면 작품이 잘린다 | 공통 박스를 포기하고 **이미지 비율을 그대로** 둔다. 행 아래끝이 들쭉날쭉해도 일정한 거터와 캡션 기준선으로 잡는다 | `ArtworkGrid`, `ArtworkFigure` |
| **Fotografiska** | 전시 글이 사진 나열이나 벽글 둘 중 하나가 된다 | 본문 사이에 **단 폭의 약 68%** 이미지를 좌우 번갈아 끼운다 → 기사가 전시를 걷는 것처럼 읽힌다 | `HistoryDetail` |
| **Rijksmuseum** | 메타데이터가 한 줄로 길게 늘어지면 아무것도 안 읽힌다 | 메타를 **이름 붙인 묶음**(자료/촬영/형태/수집·공개)으로 나눈다 | `ArtworkMeta` |
| **V&A** | 기록은 늘 불완전한데 사이트는 완결된 척한다 | **"이 기록에 대하여"** 를 두고 갱신일·출처 수·정정 요청을 밝힌다. 사진 없는 기록도 숨기지 않고 **없다고 적는다** | `RecordNote`, `work.noImage` |
| **MoMA** | 작가 페이지와 작품 페이지가 뒤섞인다 | 작가 = **서술**(생애·주요작), 작품 = **기록**(사실·출처·권리). 작품의 상세 메타를 작가 페이지에 몰지 않는다 | `ArtistDetail` / `WorkDetail` |
| **Whitney** | 큰 컬렉션에서 무엇이 얼마나 있는지 알 수 없다 | **개수를 어디에나** 붙이고, 관련 항목을 **되돌아갈 수 있는 질의**(필터 링크)로 만든다 | `ArchiveNav`, `BrowseChips`, `ArtworkMeta` 의 연도·분류 링크 |
| **MMCA** | 한국어 작품 기록의 라벨과 순서 | 관례(작가명→작품명→제작연도→재료→규격→부문→관리번호→수집경위→전시상태)를 사진 아카이브로 옮김: **촬영자 → 제목 → 촬영연도 → 매체·기법 → 규격 → 분류 → 자료번호 → 수집경위 → 공개상태** | `src/data/archive.ts` `work.*` |
| **StoryCorps** | 구술을 어떻게 '듣게' 만드는가 | 목록에서 **인용문이 제목**, 사진보다 목소리가 먼저. 전사 전문은 **기본 접힘 + 정확도 고지** | `VoiceQuote` |
| **Smithsonian** | 구술을 콘텐츠가 아니라 보존 기록으로 다루기 | **분량을 수치로**(녹음 42분 · 전사 있음) + 공개/동의 상태를 기록마다 명시 | `VoicePersonDetail` 세션 목록 |

## 의도적으로 채택하지 않은 것

- **Foam 의 pan/zoom 캔버스** — 딥링크가 어렵고 소규모 아카이브에는 과하다.
- **Rijksmuseum 의 게임형 입구** — 기록 프로젝트에서는 마케팅처럼 읽힌다.
- **V&A 식 자동생성 인물 페이지 대량 발행** — 내용 없는 페이지는 없느니만 못하다.
- **Whitney 의 색상 스와치 필터** — 실제 탐색 의도와 잘 맞지 않는다.
- **MMCA 의 라벨/값 동일 크기** — 스캔이 안 된다. 라벨은 작게·흐리게, 값은 크게.
- **StoryCorps 가 목록에서 화자 이름·날짜를 감추는 것** — 방송에는 맞지만 아카이브에는 틀리다.
- **Fotografiska 의 본문 사이 커머스 블록**, **MoMA 의 라이선스 장문 각주** — 읽는 흐름을 끊는다.
- **미술관들의 고해상도 다운로드** — 권리 확인 전에는 제공하지 않는다(`docs/archive-rights.md`).

## UdoWeb 만의 방향

- 사진 주변은 종이·흰색·회색·모래색으로 절제하고, **브랜드 시안은 링크·내비 상태·작은 악센트에만**.
  작품을 시안 카드로 감싸지 않는다.
- 명조(`--font-display`)는 **표제와 역사·구술 본문**에만. 네비·버튼·메타데이터·실시간 정보는 고딕.
  외부 폰트를 내려받지 않고 시스템 폰트로만 구성한다.
- 관광 사이트처럼 밝고 상업적이지도, 역사관처럼 엄숙하지도 않게 — 담담함·여백·시간.
- 애니메이션은 fade 와 hover 색 전환까지. parallax·scroll-jacking·커서 효과·3D 없음.
  `prefers-reduced-motion` 은 전역에서 차단한다.
